Block 4: Debounced Save on Typing
onChange={(content) => {
  if (debounceTimer.current) clearTimeout(debounceTimer.current);
  debounceTimer.current = setTimeout(() => {
    updateFile({ id: activeFile._id, content });
  }, 1500);
}}
Every keystroke resets the timer. Save happens only after user pauses typing for 1500ms. This reduces server writes and improves performance.
Debounce Concept Debounce means: delay execution until events stop happening for a fixed window. Typing generates many events; debounce collapses them into one save call after the pause.
t=0ms User types "a". Timer starts for 1500ms.
t=400ms User types again. Previous timer cancelled. New 1500ms timer starts.
t=900ms User types again. Timer cancelled again and restarted.
t=2400ms No typing for 1500ms. updateFile fires once with latest content.
